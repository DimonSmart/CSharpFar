# 0078 - Edit referenced items from search results

Related:
- 0012
- 0013
- 0046

## Goal

Allow `F4 Edit` on files shown in the search results panel without making the search results panel itself writable.

The search results panel is a virtual projection. Its rows reference underlying items; editing a file means editing that referenced item, not mutating the virtual collection.

## Effective intent

This document overrides only the conflicting `Edit` restrictions in `0012.spec-search-feature.md` and `0013.spec-dynamic-function-key-bar.md`. All other requirements in those documents remain effective.

1. The search results panel remains read-only with respect to its own structure.
2. Search results must not allow creating files or directories, deleting rows or referenced items through panel delete, renaming rows, moving items out of the panel, or copying/moving items into the panel.
3. `F4 Edit` is allowed for a file search result because it operates on the referenced underlying file.
4. `PanelProviderCapabilities.SearchResults` includes `Edit` in addition to its existing read capabilities.
5. `PanelProviderCapabilities.SearchResults` still does not include `OpenWrite`, `CreateFile`, `CreateDirectory`, `Delete`, `Rename`, `CopyTo`, `MoveFrom`, `MoveTo`, or `Watch`.
6. Editing uses the selected `FilePanelItem` location/source. It must not treat the search-results source itself as a writable filesystem.
7. Directories in search results are not editable.
8. The function-key bar must advertise `F4 Edit` when the active search result is an editable file, using the same capability check as command execution.
9. Returning from `F4 Edit` must not automatically refresh the search results panel or re-run its search. The current virtual result list remains intact until the user explicitly refreshes or starts another search.

## Acceptance criteria

- `F4` on a file in search results opens the built-in editor for the referenced file.
- Saving edits changes the referenced file, not the virtual search-results collection.
- Returning from the editor does not automatically re-run the search or rebuild the result list.
- `F4 Edit` is available in the function-key bar for editable file results.
- Search results still reject create, delete, rename, move-from, copy-to, and move-to operations.
- The capability set makes the distinction explicit instead of making the search-results panel writable.
