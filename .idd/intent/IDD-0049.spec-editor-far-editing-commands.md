# IDD-0049 - Editor Far editing commands specification

Related:
- IDD-0013 (editor function-key actions)
- IDD-0046 (editor core, undo/redo, selection and file formats)
- IDD-0050 (editor syntax commands)
- IDD-0051 (Unicode/grapheme-safe editing)

## Goal and authority

The built-in F4 editor supports Far-like text-editing commands without losing
the document, selection, bookmark, undo/redo or save behavior defined in
IDD-0046. This document owns the **editor-specific command semantics and
keyboard chords**; IDD-0046 owns the underlying editor behavior.

This specification records durable observable behavior and boundaries. It
does not require the original command-inventory workplan, preferred private
classes or staged implementation choices. The complete former document,
including the obsolete "missing commands" comparison and unresolved
implementation questions, is preserved in the
[non-normative engineering reference](../../docs/architecture/editor-far-commands-implementation-reference.md).
That historical text is not additional active product intent.

## Keyboard commands

For the editor surface, the following bindings are established:

| Chord | Behavior |
| --- | --- |
| `Ctrl+Z` | Undo the last editor transaction |
| `Ctrl+Shift+Z` | Redo the last undone transaction |
| `Ctrl+Y` | Delete the current line |
| `F8` | Delete the nonempty selection; otherwise delete the current line |
| `Ctrl+K`, `Alt+D` | Delete from the cursor to the end of its line |
| `Ctrl+Backspace` | Delete the preceding word |
| `Ctrl+Delete`, `Ctrl+T` | Delete the following word |
| `Ctrl+D` | Delete the selected block |
| `Ctrl+P` | Copy the selected block to the cursor, without using the clipboard |
| `Ctrl+M` | Move the selected linear block to the cursor, without using the clipboard |
| `Ctrl+U` | Clear the active selection |
| `Alt+U` | Unindent the selected lines or current line |
| `Alt+I` | Indent the selected lines or current line |
| `Ctrl+B` | Toggle a session-local bookmark on the current line |
| `Ctrl+N` | Navigate to the next session-local line bookmark |
| `Ctrl+Shift+0` ... `Ctrl+Shift+9` | Set the numbered bookmark in the corresponding slot |
| `Ctrl+0` ... `Ctrl+9` | Navigate to the corresponding numbered bookmark |
| `Ctrl+F` | Insert the edited file path into the document |
| `Shift+Enter` | Insert the active panel item's file name |
| `Ctrl+Shift+Enter` | Insert the passive panel item's file name |
| `Ctrl+Up`, `Ctrl+Down` | Scroll the editor viewport by one line |

`Ctrl+Y` is **not** redo. The editor intentionally favors its Far-style
delete-line meaning. `Ctrl+Shift+Z` is the editor's redo binding; this
decision also governs the core undo/redo description in IDD-0046.

Find/replace and save bindings (`F7`, modifier variants of `F7`,
`F2` and `Shift+F2`) remain defined by IDD-0046. Syntax settings
and their `Alt+H`/`Alt+L`/`Alt+T` bindings belong to IDD-0050.
Editor command descriptions, displayed function-key actions and
their actual dispatch must not conflict.

## Clipboard aliases and selection commands

- `Ctrl+Insert` is an alias for `Ctrl+C` (copy).
  `Shift+Delete` aliases `Ctrl+X` (cut).
  `Shift+Insert` aliases `Ctrl+V` (paste). They share the same
  clipboard service, selection and text-handling semantics.
- `F8` removes a selected block or the current complete line
  when no nonempty selection exists. `Ctrl+Y` deletes the current
  line. Ordinary unmodified Delete continues to delete the next
  character or join lines, as specified in IDD-0046.
- `Ctrl+D` is an explicit selected-block delete, not a synonym for
  unconditional line deletion. Mutating commands obey read-only
  restrictions; failed or inapplicable operations do not corrupt text.
- `Ctrl+P` duplicates selected text at the cursor without reading
  from or changing the clipboard. `Ctrl+M` moves a selected linear
  block only when the destination lies outside the selected range.
  The editor must not silently interpret an unsupported rectangular
  block move as an ordinary linear move.
- Shifting selected lines left/right, or the current line if no
  selection is active, updates only the relevant lines. Dedenting
  a line that has no leading tab or space leaves it unchanged.
- Word deletion uses the same configured `Editor.WordDiv`
  boundaries as word navigation and whole-word search; newline
  boundaries are handled consistently.
- Each successful destructive command is undoable and redoable
  as a coherent editor transaction and preserves meaningful cursor,
  selection, bookmark and clean/dirty state.

## Numbered bookmarks, filenames and scrolling

- The editor has session-local numbered bookmark slots `0` through `9`.
  `Ctrl+Shift+digit` stores the current position in that slot;
  `Ctrl+digit` returns to the stored position. No app-persistent
  bookmark storage is required.
- Insertion/deletion of preceding lines adjusts ordinary and numbered
  bookmarks predictably. Navigating to an unset numbered bookmark
  leaves the document unchanged.
- `Shift+Enter` and `Ctrl+Shift+Enter` use explicitly supplied
  active/passive panel item names. If the respective panel item name
  is unavailable, they fall back to the edited file's name; they do
  not silently read another panel from global application state.
  `Ctrl+F` inserts the edited file's path.
- `Ctrl+Up` and `Ctrl+Down` scroll by one viewport line, with
  bounds clamping. The caret may be brought back within the visible
  viewport if scrolling would otherwise leave it outside. These
  commands do not change document text.
- The editor domain also supports duplicating a selection/current
  line and changing the case of selected text. Those operations are
  not assigned a default key chord by this specification: their
  availability in editor-domain logic is not evidence of a user-facing
  shortcut. Future bindings require an explicit key-conflict decision,
  not an inferred chord from an older comparison report.

## Non-goals

- Do not introduce a new macro language, plugin adapter, printing path,
  LSP editor, user-configurable key-binding system or general Far
  Manager ABI compatibility through this command specification.
- No persistent numbered bookmarks.
- No binding obligation for the domain-level duplicate-selection,
  duplicate-line or case-conversion operations until a shortcut is
  explicitly specified.
- No requirement to retain the earlier command-analysis staging,
  suggested class names, temporary command inventories, or
  implementation migration workarounds.

## Acceptance criteria

1. Undo/redo use `Ctrl+Z`/`Ctrl+Shift+Z`; `Ctrl+Y` deletes a
   line instead of redoing. IDD-0046 and IDD-0049 agree.
2. Clipboard aliases copy, cut and paste exactly as the established
   clipboard chords do; they preserve ordinary text/selection semantics.
3. `F8` deletes either the selected block or the current line,
   while `Ctrl+D` deletes the selection and `Ctrl+K`/`Alt+D`
   delete only to the end of line.
4. Previous/next-word deletion honors `Editor.WordDiv` and
   can be undone without losing cursor or dirty-state correctness.
5. `Ctrl+P` copy, `Ctrl+M` move, `Ctrl+U` clear-selection,
   and `Alt+U`/`Alt+I` line transforms obey the described
   selection policies; unsupported block moves do not corrupt text.
6. `Ctrl+Shift+0`...`9` set numbered slots and
   `Ctrl+0`...`9` navigate to them; their positions stay meaningful
   after text edits.
7. `Ctrl+F` and modified Enter insert the correct editor/panel
   paths or names, with the documented missing-item fallback.
8. `Ctrl+Up`/`Ctrl+Down` scroll within viewport bounds and
   maintain a valid visible caret.
9. Save, find/replace, Unicode, clipboard and base editor behaviors
   described in IDD-0046 remain unaffected. Bound commands agree
   with command inventory and displayed labels.

## Verification

- Exercise exact keyboard chords for undo/redo/delete-line; assert
  that `Ctrl+Y` never invokes redo and `Ctrl+Shift+Z` never
  deletes a line.
- Cover clipboard aliases, `F8` with/without selection,
  delete-to-end-of-line and word deletion around configured word
  separators.
- Verify transaction undo/redo for block copy, move, delete and
  line shifts, plus read-only and invalid-selection behavior.
- Verify numbered bookmark setting/jumps and line-shift behavior
  after insertion/deletion, including unset slots.
- Check context-sensitive active/passive filename insertion,
  edited-file path insertion and viewport scrolling boundaries.
- Check that the documented chord inventory has no duplicate
  implemented bindings and that file editor function-key actions
  agree with their command implementations.
